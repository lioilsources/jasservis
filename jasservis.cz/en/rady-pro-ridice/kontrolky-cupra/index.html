EPC – petrol engine management

Yellow / amber · Warning · Steady

Meaning

The petrol engine management system has detected a fault. EPC does not identify a particular failed component.

Recommended action

Arrange engine inspection promptly. Brief illumination with the ignition on is a check; the lamp should go out after starting.

Electric drive coolant warning

Red · Warning · Flashing

Meaning

On the listed Born, coolant temperature is too high or coolant level is too low. This is a separately documented electric-drive application.

Recommended action

Stop safely, switch off the drive and allow it to cool. Check as instructed; do not open a hot reservoir. If the warning remains despite the correct level, do not continue and seek professional assistance.

Key indication

Together with the red high-voltage symbol this is a different combined warning: stop immediately, switch off the drive and seek assistance. This is not general permission to add coolant to an overheated high-voltage system.

ESC/TCS – deactivation or Sport mode, OFF symbol

Yellow / amber · Operating information · Steady

Meaning

In this edition, the amber skidding-car OFF symbol denotes manual TCS deactivation, ESC Sport or manual ESC deactivation, depending on equipment and message. It is not conflated with flashing intervention or a steady fault indicated by the plain skidding-car symbol.

Recommended action

Check the selected mode. Limited or disabled stability control changes the safety margin; select the mode only under suitable conditions following the manual.

Key indication

Some versions also use a separate ESC OFF inscription. That different graphic is not presented here as the same image.

ESC OFF – stability control switched off

Yellow / amber · Operating information · Steady

Meaning

The separate amber ESC OFF inscription indicates deactivated stability functions according to the specified manual. Not automatically a fault and not the plain skidding symbol.

Recommended action

Allow for the reduced safety margin. Use the mode only when required by conditions and allowed by the manual; restore stability control as soon as possible.

Key indication

Distinguish Sport mode, TCS deactivation and full ESC deactivation by message and exact symbol. An ignition function-check phase may occur.

Brake servo – restricted operation, amber warning · multiple meanings of the same symbol

Brake servo – restricted operation, amber warning

Yellow / amber · Warning · Steady

Meaning

With the documented amber warning, electromechanical braking assistance is restricted. Pedal pulsations may occur and stopping distance can increase.

Recommended action

Allow for greater brake-pedal effort and seek professional service. Other simultaneous messages, including STOP, take priority; amber is not universal assurance that continued travel is safe.

Key indication

Different from red servo failure with the instruction not to continue. In another message the same sign can refer to another brake component; exact text and cited edition are decisive.

Electronic parking brake – amber fault (Terramar)

Yellow / amber · Warning · Steady

Meaning

This version’s amber message indicates an electronic parking-brake fault. It is not the normal red confirmation that the parking brake is applied.

Recommended action

Visit a specialist workshop. When parking, ensure the vehicle is safely secured against movement and follow the exact message. Any simultaneous STOP warning takes priority.

Key indication

Verified for Terramar 11.2025, overview p.13 and specific fault instructions pp.228–229. The same amber circular sign can indicate restricted brake assistance with a different message; the meanings are separate.

Meaning

White · Operating information · Control marking (not a warning)

Meaning
